Privacy Policy

VomeSync is a community directory and Home Assistant integration for sharing remote switch states. This page is a plain-language summary for the live preview.

What data is shown publicly

Only switches that have been publicised by their owner are listed publicly. Public listings may include a description, category, and city-level location (if provided), plus high-level usage statistics.

What data is used for authentication

The Home Assistant integration uses a personal key to authenticate API requests for switch creation and management. Keep this key private.

What to avoid

Do not publicise or share switches that control sensitive devices (locks, alarms, security systems). Public switches can be toggled by anyone who has the UID.
