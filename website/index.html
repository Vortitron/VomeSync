    How to Use

    1. Install VomeSync

    Add the VomeSync integration to your Home Assistant via HACS.

    Open in HACS

    2. Copy UID

    Click the copy button next to any switch below to copy its unique identifier.

    3. Subscribe

    Use the UID in VomeSync configuration to create a monitoring sensor in your Home Assistant.

    4. Automate

    Create automations that react to remote switch state changes.
